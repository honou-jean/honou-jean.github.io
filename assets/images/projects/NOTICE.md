# Project cover photo sources

Real photographs used as project-card and detail-page cover images, replacing the earlier CSS-only placeholder diagrams at the owner's request. Each image is a real, thematically related photograph — not a screenshot or figure from the actual projects, which do not yet have public visual material of their own.

- `biometrics/cover.jpg` — [Iris Macro, Eye close-up](https://commons.wikimedia.org/wiki/File:Iris_Macro,_Eye_close-up_(11622304153).jpg) by Matt Ming, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). Cropped and re-encoded for web delivery.
- `poisson/cover.jpg` — [Close-up of an electric car charging station](https://commons.wikimedia.org/wiki/File:Close-up_of_an_electric_car_charging_station.jpg), [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). Cropped and re-encoded for web delivery.

Both are sourced from Wikimedia Commons and were chosen to avoid featuring identifiable people, brand-heavy scenes, or any claim of depicting the real systems described on this site.

- `dashboard-prets-immobiliers/*.jpg` — real screenshots exported from the Power BI report itself (own work), resized and re-encoded as JPEG for web delivery. Unlike the two entries above, these do depict the actual project.
- `poisson/resultat-acn-data.jpg`, `poisson/resultat-nyc311.jpg` — real result figures generated by the owner's own analysis (own work), resized and re-encoded as JPEG for web delivery.
- `scientific-computing/cover.jpg` — the project's own DistMesh triangulation (own work): rendered directly from the group's `node.txt`/`tri.txt` mesh output (finest mesh, 1000-triangle target) with Matplotlib, tinted to the site's navy/teal palette.
- `scientific-computing/resultat-convergence.jpg` — the project's own convergence result (own work): a log-log plot of the maximum and RMS error against the number of interior nodes, built from the group's three-mesh comparison (`comparaison_solutions_q4e.txt`) with Matplotlib.
- `conservation-law-shocks/cover.jpg`, `conservation-law-shocks/comparaison-apres-choc.jpg` (identical image, two file names for the hero banner and the in-body figure) — the project's own shock-comparison result (own work): the exact vs. Lax-Wendroff solution at T = 1.4, re-rendered from the project's own scheme with Matplotlib, tinted to the site's navy/teal palette.
- `conservation-law-shocks/comparaison-avant-choc.jpg` — the project's own pre-shock comparison result (own work): the exact vs. Lax-Wendroff solution at T = 1.0, re-rendered from the project's own scheme with Matplotlib, tinted to the site's navy/teal palette.
- `conservation-law-shocks/resultat-cfl.jpg` — the project's own CFL stability result (own work): the periodic Lax-Wendroff solution at several CFL values, re-rendered from the project's own scheme with Matplotlib, tinted to the site's navy/teal palette.
